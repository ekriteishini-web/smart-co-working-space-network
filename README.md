# Smart Co-Working Space Network Design using Cisco Packet Tracer

## Project Overview

Designed and simulated a secure smart co-working space network infrastructure using Cisco Packet Tracer. The project focused on creating a scalable and reliable multi-floor network environment that supports wired devices, wireless users, IoT systems, and external connectivity while maintaining proper network segmentation and security.

The network was designed to support administrative staff, private office tenants, freelancers, guests, and smart facility management systems within a modern co-working environment.

---

## Network Design Features

### Multi-Floor Infrastructure

* Ground Floor:

  * Reception area
  * Administrative office
  * Guest lounge

* First Floor:

  * Private office suites
  * Freelancer hot-desk area
  * Conference rooms

### Network Infrastructure

* Router and switch configuration
* Wired and wireless connectivity
* DHCP implementation
* Static IP assignment for critical devices
* Wireless access point deployment

### VLAN Segmentation

Implemented VLAN segmentation to improve network organization and security:

* VLAN 10 – Administration
* VLAN 20 – Tenants & Freelancer Devices
* VLAN 30 – Guest Wi-Fi
* VLAN 40 – IoT & Smart Devices

### IoT & Smart Features

Integrated smart facility devices including:

* RFID smart door locks
* IP surveillance cameras
* Smart lighting systems
* Wireless projectors

### Security & Connectivity

* Configured inter-VLAN routing
* Restricted guest network access from internal resources
* Enabled external server/internet connectivity
* Applied basic access control principles
